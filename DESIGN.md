# Design System — Ernest Mwinchumu Portfolio

## Direction

**Editorial hybrid** — reads like a serious personal site (normal), with one exotic thread: serif display type on names and section titles, warm navy/cream, coral used sparingly.

Avoid: centered everything, icon-in-circle grids, floating pill nav, dashed placeholder badges, stacked card sections, Aceternity spotlight blobs.

## Typography

- **Display:** Instrument Serif — hero name, h2 section titles
- **Body / UI:** Geist Sans
- **Meta / labels:** Geist Mono at small sizes

## Color

- Navy `#0B1F3A`, cream `#F5F1E8`, coral `#FF6B5E` (CTAs and links only)
- 60 / 30 / 10 rule from build brief

## Layout

- Max width `max-w-5xl`, left-aligned section headers
- Lists and dividers over card grids
- Section rhythm: label → title → body, generous vertical space

## Motion

- Hero: none or minimal fade
- Rest: CSS hover only; respect `prefers-reduced-motion`

## Placeholders

- `[Confirm: …]` in muted mono footnotes — not coral dashed chips
